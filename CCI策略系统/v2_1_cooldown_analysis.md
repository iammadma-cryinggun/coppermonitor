## 代码实现检查

### backtest_v2_with_cooldown.py 的冷却逻辑

```python
# 冷却机制检查（关键修改！）
if position == 0:
    if last_exit_date:
        days_since_last_exit = (current_date - last_exit_date).days
        if days_since_last_exit < params['cooldown_days']:
            # 还在冷却期，不开仓
            continue
```

**逻辑看起来正确，但为什么交易数没有减少？**

### 可能原因分析

1. **日期计算问题**：
   - `df_year.index[i]` 可能不是datetime类型
   - `days_since_last_exit` 计算可能异常

2. **平仓后立即跳过**：
   - 冷却逻辑只检查 `position == 0` 时
   - 如果平仓和开仓在同一天，可能绕过冷却

3. **数据跳过问题**：
   - 市场可能有周末、假期
   - 3个自然日 vs 3个交易日
