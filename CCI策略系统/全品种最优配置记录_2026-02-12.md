## 🔧 论文因子使用指南

### 隔夜缺口因子（Gap Factor）

**适用品种**: 白银、铜、纯碱、玻璃、铅、棉花、锌

**阈值选择规律**:
```
高波动品种（白银）: -0.35
一般品种: -0.15 ~ -0.20
低波动品种（棉花）: -0.10
```

**因子公式**:
```python
gap = (今日开盘价 - 昨日收盘价) / 昨日收盘价
normalized_gap = gap / (近期最高价 - 近期最低价) / 当前价格

# 如果 normalized_gap < threshold，则不开仓
```

### 趋势质量因子（Trend Quality）

**适用品种**: 镍、铝

**阈值**: 0.25 ~ 0.30

**因子公式**:
```python
# 趋势质量 = 方向一致性 × 低波动 × 流动性
direction_consistency = 近期涨跌方向一致性
volatility_quality = 1 / (当前ATR / 近期平均ATR + 0.1)
liquidity_quality = min(当前量比, 2) / 2

# 如果 trend_quality < threshold，则不开仓
```

## ⚠️ 重要提示

### 实盘使用建议

1. **收益率打折**: 回测收益 × 60-70%
2. **回撤放大**: 实际回撤可能比回测大10-15%
3. **避免品种**: 黄金（回撤-87%）、糖（收益太低）
4. **最佳组合**: 白银 + 铜 + 玻璃

### 论文因子使用建议

✅ **强烈推荐**:
- 白银、铜、玻璃、棉花、锌（隔夜缺口因子）

⚠️ **可选**:
- 纯碱、铅（隔夜缺口小幅提升）

- 锡、黄金（保持原始策略）
