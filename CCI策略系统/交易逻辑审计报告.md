## 一、发现的回测陷阱

### 1. ❌ 偷价问题（Stop Loss）

**原逻辑**:
```python
if next_low <= entry_price * 0.96:
    pnl = (next_open - entry_price) * position * multiplier
```

**问题**:
- 假设能在次日开盘价止损
- 但实际当日最低价已经触及止损，根本等不到次日

**修正**:
```python
# 实际止损价格：取开盘价和止损价的较大者
stop_price = max(next_day['open'], entry_price * 0.96)
exit_price = apply_slippage(stop_price, 'sell')
```

### 2. ❌ 滑点缺失

**原逻辑**: 完全没有考虑滑点

**修正**: 添加万二滑点
```python
def apply_slippage(self, price, direction='buy'):
    if direction == 'buy':
        return price * (1 + 0.0002)  # 买入价+0.02%
    else:
        return price * (1 - 0.0002)  # 卖出价-0.02%
```

### 3. ❌ 手续费缺失

**原逻辑**: 没有手续费

**修正**: 添加万三手续费
```python
def calculate_commission(self, price, qty):
    return price * qty * multiplier * 0.0003
```

### 4. ❌ 杠杆计算混乱

**原逻辑**:
```python
qty = int(balance * 0.9 * 2 / (next_open * multiplier))
```

**问题**: multiplier只是合约乘数，不是杠杆

**修正**: 明确杠杆定义
```python
self.leverage = 2  # 实际使用的杠杆
max_value = balance * 0.9 * self.leverage
qty = int(max_value / (entry_price * self.multiplier))
```
