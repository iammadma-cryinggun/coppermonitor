### 发现2：v3的5笔分批止盈交易示例

- **分批止盈逻辑有严重错误**

## 六、根本原因分析

### 问题1：v2为什么只有2笔交易？

从之前完整回测v2在2025年是56笔，但analyze_2025_comparison.py中只有2笔。

**原因**：analyze_2025_comparison.py中实现的v2逻辑不完整

### 问题2：v3分批止盈触发错误

```
2025-09-16分批止盈：-27205.44
```

**分批止盈条件**：
```python
if profit_atr > 2.5:  # 盈利超过2.5 ATR
    close_size = position_size // 2  # 平半仓
```

**问题**：
- 当价格向不利方向变动时，profit_atr可能是正数（做空时价格下跌）
- 但如果价格随后反弹，触发半仓时实际是亏损

**根本原因**：分批止盈只检查ATR倍数，不检查实际盈亏方向
