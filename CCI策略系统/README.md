# CCI策略系统

**最后更新**: 2026-02-11
**版本**: 1.0 (严格回测版)

---

## 系统概述

基于CCI（商品通道指数）和STC（Schaff趋势周期）的中国期货市场交易策略系统。包含12个品种的参数优化和严格回测验证。

## 交易规则

### 开仓信号
- **超卖反弹**: `CCI < cci_oversold AND STC >= stc_oversold` → 次日开盘买入
- **金叉确认**: `CCI上穿CCI_MA AND CCI <= cci_cross_max AND STC >= stc_cross` → 次日开盘买入

### 平仓信号
- **止损**: 亏损 4% (日内触发)
- **止盈**: 盈利 20% (日内触发)
- **CCI超买**: `CCI > cci_overbought` → 收盘平仓
- **CCI死叉**: `CCI下穿CCI_MA` → 收盘平仓

### 仓位管理
- 基础仓位: 可用资金 × 90% × 2倍杠杆
- 单品种限制: 不超过总资金30%
- 交易成本: 滑点0.02% + 手续费0.03%

---

## 风险提示

1. **收益率打折**: 实盘收益 ≈ 回测 × 60-70%
2. **回撤放大**: 实际回撤可能大10-15%
3. **连续亏损**: 可能连续5-10次亏损
4. **黄金避免**: 回撤-87%，任何风控都无效
5. **长期坚持**: 需要1-2年才能体现策略优势

## 每日使用流程

### 1. 盘后检查 (19:00-20:00)
```bash
python 全品种市场分析.py
```
查看所有品种的当前信号、止盈止损价格

### 2. 记录数据
```bash
python 每日数据记录.py
```
保存每日价格、指标、信号到CSV

### 3. 执行交易
- 买入信号 → 次日开盘执行
- 严格执行止损止盈

### 4. 复盘分析
```bash
python 每日数据记录.py --view 30
```
查看最近30天的信号记录
