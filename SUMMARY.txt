快速开始
========================================================================

1. 创建定时任务（推荐）
   - 右键点击 setup_task.bat
   - 选择"以管理员身份运行"
   - 任务将每4小时自动运行

3. 手动运行测试
   - 双击 run_monitor.bat
   - 或运行: python copper_monitor.py

4. 查看分析报告
   - 运行: python analyze.py

========================================================================
故障排查
========================================================================

定时任务未运行:
  1. 检查任务: taskschd.msc (查找"沪铜监控")
  2. 手动运行: run_monitor.bat
  3. 查看日志: logs/strategy_monitor.log

数据获取失败:
  1. 检查网络连接
  2. 系统会自动降级到CSV备用
  3. 查看日志了解详情

========================================================================
管理命令
========================================================================

删除定时任务:
  schtasks /Delete /TN "沪铜监控" /F

查看任务信息:
  schtasks /Query /TN "沪铜监控" /FO LIST /V

立即运行任务:
  schtasks /Run /TN "沪铜监控"

查看日志:
  type logs\strategy_monitor.log
